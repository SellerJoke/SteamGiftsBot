## 一、项目介绍
基于Python的SteamGifts机器人，用于自动参与SteamGifts网站的赠送。
## 二、功能
1. 自动抓取SteamGifts网站的赠送列表并保存到本地。
2. 自动抓取Steam游戏评价信息并保存到本地，每7天更新一次。
3. 将赠送按照游戏评价排序，自动参与高评价游戏的赠送，如果点数不足，自动退出低评价游戏的赠送获取点数；保存参赠状态到本地。
## 三、运行方法
1. 安装Python，并配置环境变量，可参考[一文教你如何在Windows下安装 Python 环境 - 知乎](https://zhuanlan.zhihu.com/p/1969557833444992216)
2. 在项目/resources/config.yml中配置PHPSESSID，或者在运行过程中按照提示输入PHPSESSID。
3. 双击项目根目录下的SteamGiftsBot.bat文件即可运行。
## 四、FAQ
1. 为什么运行过程中有些赠送没有按照评级排序？  
答：因为评级的计算与赠送的参与人数有关，而参赠人数在参赠前后发生了较大变化。
在参赠之前，先按参赠人数等数据计算评级对赠送排序。参赠之后，又抓取了参赠人数，这时参赠人数与参赠前相比可能发生较大变化，进而导致评级发生变化。而此时赠送还是按照参赠之前的旧数据排序的，因此对新数据来说，赠送列表的排序就不正确了。新数据和旧数据的抓取时间间隔在2分钟以内，大多数情况下，新数据和旧数据的排序是大体相同的。
